Frequently asked questions

Is the API compatible with AWS S3?
Yes, our Object Storage is fully S3-compatible. You can use the standard AWS SDKs, CLI tools, and existing libraries without changing your code—just update the endpoint URL.
Are there really no egress fees?
Absolutely. We believe you shouldn't be penalized for accessing your own data. We charge a flat rate for storage and operations, but bandwidth out to the internet is free.
Can I migrate existing buckets?
Yes. We provide a background migration tool called "Bucket Sync" that replicates data from AWS S3, Google Cloud Storage, or Azure Blob Storage to your new buckets automatically.
